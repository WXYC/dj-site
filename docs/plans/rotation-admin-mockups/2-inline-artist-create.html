Annotations

  1. 1Matches are genre-scoped, like the real searchArtistsInGenre — switch the genre and the same search returns different rows (and a held selection is cleared, mirroring handleGenreChange).
  2. 2The create row exists in ArtistSearchTypeahead today (CREATE_HIGHLIGHT); only its handler changes — from "show an advisory telling the MD to leave" to expanding this panel. Every consumer of the typeahead inherits the fix.
  3. 3suggestCallLetters() already exists (lib/features/rotation/importSuggestions.ts) — today it's only used on the rotation import screen. Edit the letters and watch the peek recompute.
  4. 4GET /library/artists/peek-code already returns this number; today three forms render it read-only and make the MD retype it. "Use N" is the one-click accept. The conflict banner mirrors the code-triple 409 from adminCreateArtistValidation.ts — try SL 1 in Rock (Stereolab's code).
  5. 5On create, the panel collapses to a selected chip and the release fields are exactly as you left them — no modal exit, no retyping. What happens after "Add release" is mockup C's subject.
