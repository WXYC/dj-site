Rotation filing — interactive demos

Working demos against a small in-memory WXYC library. The consolidated direction is at the top; the earlier explorations that fed it are kept below with their status.

Rotation Admin  current direction

The bench is the way rotation items are created, and it lives in the admin interface as its own Rotation Admin area — no Add Release button on the catalog page. Three separate views: "Add to rotation" (match-or-create artist → file release → bin → card; code number auto-fills from the peek), the "Rotation list" (search + bin filters + card sub-filter, Kill/Unkill, bin moves via add-then-kill, per-row card reassignment), and "Cards" — bins subdivide into numbered, optionally-named cards (1…N per bin), modeled nowhere in the system today; the tab renames, adds, and deletes them. Partial-failure ledger with Retry included.

Catalog Search — Rotation Location  current direction

Companion surface to the admin area: a release in rotation is not on the stacks, so for actively-rotating rows both experiences' catalog search results swap the call-number cell for the record's real location — bin + card (card name in the tooltip). Flag toggle shows before/after; ships behind the same NEXT_PUBLIC_ROTATION_ADMIN_ENABLED flag.

Rotation Age & Card Staleness  proposal

Answers the MD ask for the site to say "[x] album has been in Medium 7 [for] [x] days" and "Light 6 has not been updated in [x] days". Two additions to surfaces that already exist: per-record age on the Rotation list (with sort-by-oldest and a per-bin replacement window), and per-card last activity on the Cards tab, counting kills as well as adds. Three nudge treatments — quiet, flagged, loud — are switchable at the top. The record age is free from data already on the wire; card dwell time is not derivable and would need a card_assigned_at column, which the page marks rather than fakes. Thresholds are placeholders for the MDs to set.

Card Assignment Panel  proposal

The tool for the one-time re-carding pass (B3 of the rotation age epic). The launch backfill put every active record on card 1 of its bin, and the only way to move them today is one select per record. From the Cards tab, Assign records on a card opens a panel listing its bin's active records: tick what is physically on the card, save, and move on to the next with Save & open Heavy 4. Records already on the card are locked (a record leaves a card only by being ticked onto another), a Still on Heavy 1 filter narrows to the backfill pile, and saving sends one batch with a per-record result and a retry for failures. A request counter shows the cards list refetching once per save, not once per record.
